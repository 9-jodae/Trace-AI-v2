- 공백 원문·잘못된 유형·빈 권한·버전 번호·날짜·추가 필드 거부.
- 원본 분류 우선, LLM의 권한·문서 ID 변경 금지.
- 원문에 없는 인용 제거와 실제 인용 문자 위치 계산.
- 미분류·추출 한도·잘못된 출력·LLM 장애의 검토 대기 처리.
- 주제·참조 중복, 자기 참조, 대상 없음·동일 제목 여러 문서 처리.
- Qdrant 메모리 모드에서 검토 대기 원문 검색, STAGING 숨김과 공개.
- 문서별 Chunk 회수의 버전·그룹 필터와 그래프 문서 순서 유지.
- 문서·버전으로 한정된 정리, 현재 문서 확인 실패 시 근거 차단.
- 문서 중심 Neo4j 쿼리의 전달 인자·트랜잭션·원문 비로그 처리.
- 내부 적재 API의 요청 검증·인증·409 오류·본문 비노출.
- 기존 채팅·JEV·RRF·메모리 대화 상태·로컬 브라우저 화면 회귀.

## 검증하지 않은 사항

- 실제 Neo4j 서버에서의 Cypher 실행, 인덱스 준비 시간, 동시 갱신·잠금 동작.
- 운영 Qdrant 서버·실제 임베딩 모델·LLM을 사용한 적재와 분류 품질.
- PDF/DOCX·스캔 원본 파싱, Notion/Drive API 연동.
- Spring의 실사용 AccessScope·파일 요청·비동기 콜백 연동.
- 사용자 실제 문서로 측정한 검색 정확도·분류 정확도·비용 절감률·성능.

Neo4j 테스트는 드라이버 대역이며 Qdrant는 메모리 모드를 사용한다. 로컬 브라우저 테스트도 가짜 AI 응답 서버를 사용한다. 이 결과를 운영 통합 검증으로 해석하지 않는다.
