# 별도 로컬 데모 참고

이 문서는 AI 레포에 코드를 가져오기 전, 별도 작업 폴더에 있던 데모를 읽어 확인한 기록이다. **현재 이 레포의 구현 상태를 설명하지 않는다.** 기능 구현의 기준은 [프로젝트 기획서](프로젝트_기획서.md)다.


2026-11-05에 파일을 읽어 확인한 상태다. 실행 검증 결과를 의미하지 않는다.

| 항목 | 현재 데모 | 최신 기획 |
|---|---|---|
| 검색 실행 | 매 질문마다 Qdrant 벡터·Neo4j Full-text 검색 | JEV가 신규 검색 필요 판정 시 두 경로 검색 |
| 컨텍스트 재사용 | 구현되어 있지 않음 | 도입 예정 |
| Neo4j 구조 | `Document`와 `Chunk`, `HAS_CHUNK`, 문서 간 관계 | 업무 노드는 `Document` 중심. 기술적 Chunk 노드 유지 여부는 결정 필요 |
| 그래프 관계 | 최종 근거와 연결된 관계를 부가 표시 | 관계를 검색 후보 확장에 활용하는 방식 검토 |
| RRF | Chunk ID 중복 제거, 동일 가중치, k=60 | 방식은 유지하되 세부 파라미터는 평가 후 결정 |
| 실행 순서 | Qdrant 조회 후 Neo4j 조회 | 독립 검색의 병렬화 검토 |
| 모델·화면 | Ollama 및 Streamlit 데모 | 이 문서에서 최종 운영 기술로 확정하지 않음 |
| 접근 제어 | 그룹 필터 시연 | 인증 사용자 기반 적용 및 재사용 시 검증 필요 |

참고한 로컬 파일은 `README.md`, `rag_demo/engine.py`, `rag_demo/storage.py`다. 이 파일들은 현재 AI 레포에 포함하지 않았다. 데모의 기존 `Document + Chunk` 저장 방식과 최신 문서 중심 그래프 기획은 구분해서 후속 설계를 진행한다.
