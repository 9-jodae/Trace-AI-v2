# 저장소 이전 기록

2026-11-05에 AI 서버 저장소를 `9-jodae/docs199-AI`에서 `9-jodae/docs199-AI-v2`로 옮겼습니다. 이후 개발은 새 저장소에서 합니다.

## 이전 이유

11-04 23:58 UTC쯤부터 기존 저장소의 브랜치 갱신이 모두 실패했습니다.

- `git push`가 `remote: fatal error in commit_refs`로 거부됩니다. 새 브랜치, 빈 커밋, 새 clone에서도 같습니다.
- REST API로 브랜치를 만들어도 422 `Reference update failed`가 납니다. 파일 객체(blob) 쓰기는 됩니다.
- 같은 계정으로 `docs199-Server`와 새 저장소에는 push가 됩니다.
- 저장소 규칙과 보호 브랜치는 없고, 계정 권한은 `admin`입니다.

원인은 확인하지 못했습니다. 기존 저장소 쪽 문제로 보입니다.

## 달라진 점

- 이슈와 PR의 작성자가 이전을 실행한 계정으로 바뀌었습니다. 본문 첫 줄에 원작성자와 작성 시각, 원본 번호를 적었습니다.
- 이슈와 PR의 시각은 이전한 시각으로 바뀌었습니다.
- 멘션이 다시 알림을 보내지 않도록 옮긴 글의 `@`를 코드 표기로 바꿨습니다.
- 기존 저장소의 CI 기록과 웹훅 전송 기록은 옮겨지지 않습니다.

## 원본에 없던 것
