## 최신 AI 처리 방향

1. JEV가 기존 근거 컨텍스트만으로 질문에 답할 수 있는지 판단합니다.
2. 재사용할 근거의 권한·버전이 유효하면 해당 근거로 답변합니다.
3. 신규 검색이 필요하면 Neo4j와 Qdrant를 모두 조회합니다.
4. 두 경로의 결과를 Chunk 단위로 맞추고 RRF로 융합합니다.
5. 최종 상위 Chunk를 사용해 LLM이 근거와 출처가 있는 답변을 작성합니다.

문서 청킹은 문서 적재·내용 변경 시 수행합니다. 사용자 질문마다 문서를 다시 청킹하지 않습니다. Neo4j의 문서 단위 결과를 Chunk로 변환하는 구체적인 방식은 기획서의 추가 결정 사항에 기록했습니다.
